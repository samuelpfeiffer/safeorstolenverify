## TROUBLESHOOTING

### If a URL shows "Not Indexed" after 1 week:

1. **Go to:** URL Inspection tool
2. **Enter:** The problem URL
3. **Check:** Why it's not indexed
4. **Click:** "Request Indexing" again
5. **Wait:** 3-5 more days

### Common Issues:
- **"Crawled - currently not indexed"** → Normal, Google will index soon
- **"Discovered - currently not indexed"** → Request indexing again
- **"Alternate page with proper canonical tag"** → Should be FIXED now
- **"Soft 404"** → Check that page exists and has content

## IMPORTANT NOTES

### Google Search Console Limits:
- Maximum 10-12 manual indexing requests per day
- Spread requests across multiple days as shown above
- Don't spam - it won't make indexing faster

### Timeline:
- **Immediate:** Some pages may index within 1-3 days
- **Normal:** Most pages index within 1-2 weeks
- **Slow:** Some pages may take 3-4 weeks
- **Total Time:** Expect 95%+ indexed within 30 days
