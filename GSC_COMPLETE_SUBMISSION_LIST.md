## Troubleshooting

### If Pages Still Show Soft 404:
1. Wait 48 hours after requesting indexing
2. Check page loads properly in browser
3. Verify structured data with: https://search.google.com/test/rich-results
4. Request indexing again

### If Hit Rate Limit:
- Google typically limits to 10-20 manual requests per day
- Wait 24 hours and continue
- Focus on highest priority pages first

### If Page Says "Cannot Index":
- Check robots.txt allows the page
- Verify canonical tag is correct
- Ensure page returns 200 status code
- Check for redirect loops
