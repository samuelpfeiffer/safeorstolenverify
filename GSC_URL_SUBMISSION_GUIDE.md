## 🚨 Common Issues & Solutions

### Issue: "URL is already indexed"
**Solution:** Great! Skip to next URL. No action needed.

### Issue: "URL has crawl errors"
**Solution:** Check the specific error in GSC. Usually caused by:
- Broken canonical tags → Fixed ✓
- Invalid structured data → Fixed ✓
- Server errors (500) → Check Cloud status

### Issue: "Discovered - currently not indexed"
**Solution:** This is normal. Google discovered it but hasn't indexed yet. Wait 3-7 days.

### Issue: "Duplicate without user-selected canonical"
**Solution:** This should NOT happen anymore. If it does, report immediately.
