## 🚨 TROUBLESHOOTING COMMON ISSUES

### Issue 1: "URL is not on Google"
**Cause:** Page not crawled yet  
**Solution:** 
1. Wait 3-5 days
2. Re-submit via URL Inspection
3. Check robots.txt isn't blocking

### Issue 2: "Discovered - currently not indexed"
**Cause:** Low crawl priority  
**Solution:**
1. Build internal links to page
2. Submit parent sitemap again
3. Re-request indexing

### Issue 3: "Crawled - currently not indexed"
**Cause:** Low quality signals or duplicate content  
**Solution:**
1. Improve content uniqueness
2. Add more relevant keywords
3. Build backlinks to page

### Issue 4: "Excluded by 'noindex' tag"
**Cause:** Page has noindex meta tag  
**Solution:**
1. Check PageSEO `noIndex` prop
2. Remove or set to `false`
3. Re-submit for indexing

### Issue 5: "Redirect error"
**Cause:** URL redirects to another page  
**Solution:**
1. Submit the final destination URL instead
2. Or remove redirect if unintended
