### Screenshot Capture Instructions

**Best Practices:**
1. Use clean browser window (no bookmarks bar)
2. Capture at 2560x1440 resolution, then scale to 1270x760
3. Use actual data, not placeholder content
4. Hide any personal information
5. Use high-quality example data
6. Ensure text is readable when scaled

**Tools:**
- Mac: Cmd+Shift+4, then press Space
- Windows: Snipping Tool or Windows+Shift+S
- Browser: DevTools responsive mode for mobile views
- Design Tools: Figma, Canva for composites
