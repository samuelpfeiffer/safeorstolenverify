Frequently Asked Questions

Does SafeOrStolen use Bike Index data?

Yes! When you check a bicycle serial number on SafeOrStolen, we query the Bike Index API along with other databases. You get Bike Index coverage plus additional sources like police reports and insurance databases.

Is Bike Index really 100% free?

Yes, Bike Index is a nonprofit open-source project that's completely free. They're funded by grants and donations. The tradeoff is they only cover bicycles - no phones, cars, or other items.

Which should I use for buying a used bike?

Use both! Check Bike Index (free, unlimited) and SafeOrStolen (comprehensive coverage). If you also buy phones, cars, or electronics, SafeOrStolen's all-in-one platform saves time. If you only buy bikes, Bike Index alone may suffice.
