# Instructions to Get Your Site Indexed on Google

## 1. Set up Google Search Console
1. Go to https://search.google.com/search-console/
2. Add your property: https://safeorstolen.com
3. Verify ownership using the HTML meta tag method
4. Replace "pending-verification" in GoogleSearchConsoleSetup.tsx with your verification code

## 2. Submit Your Sitemap
1. In Google Search Console, go to Sitemaps
2. Submit: https://safeorstolen.com/sitemap.xml

## 3. Set up Google Analytics (optional but recommended)
1. Go to https://analytics.google.com/
2. Create a new property for safeorstolen.com  
3. Get your GA4 measurement ID (starts with G-)
4. Replace "G-PENDING" in GoogleSearchConsoleSetup.tsx with your ID

## 4. Request Indexing
1. In Google Search Console, use URL Inspection tool
2. Enter your homepage URL: https://safeorstolen.com
3. Click "Request Indexing"

## 5. Submit to Bing (optional)
1. Go to https://www.bing.com/webmasters/
2. Add and verify your site
3. Submit your sitemap there too
